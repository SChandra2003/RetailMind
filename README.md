# RetailMind AI

## Project Overview

RetailMind AI is an end-to-end retail intelligence
platform designed to provide machine learning
solutions for business problems.

## Day 1 - Customer Churn Prediction

### Objective
Build a machine learning pipeline to predict
customer churn.

### Dataset
Telco Customer Churn Dataset - Kaggle

### Technologies
- Python
- Pandas
- Scikit-learn
- Joblib

### Workflow
1. Data ingestion
2. Data inspection
3. Data preprocessing
4. Model training
5. Model evaluation
6. Model persistence
7. Prediction service
